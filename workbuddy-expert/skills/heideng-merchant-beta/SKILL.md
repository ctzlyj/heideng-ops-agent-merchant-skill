# 黑灯商家内测

首次受理任务即从本技能目录调用 `python -I -B scripts/beta.py status`。资格由运营方分配的专用 LTS4AI Key 验证，商家在本机安全窗口填写。资格就绪后按交办目标读取 `references/experience-navigation.md` 及相应经验页。商家在京麦页面确认目标店身份。

本专家内的商家命令统一从 `python -I -B scripts/beta.py <原子命令和参数>` 执行。宿主将经验页及历史回执中的业务动作交给同一入口；它负责核验资格、定位版本和隔离状态，并向生图客户端注入专用 Key。首次连接中转站没有产生图片。重新录入使用 `activate`，退出本机资格使用 `forget-key`。

沿用当前任务的同店原回执与已确认范围。先做可独立推进的工作，报价给出新增张数与积分上限；gpt-image-2.5 和 gpt-image-2.6 同分辨率同价，1K、2K、4K 每张分别为 3、4、5 积分。额度由中转站执行。额度用尽且中转站仍明确确认资格时可继续非生图业务；无法核实资格时请运营方核对。用原任务账本追踪结果未知的写入或图片请求。向商家交付可核验的原件、准确规格链接及实际状态。
