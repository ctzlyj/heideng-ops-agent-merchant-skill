# 新品与复刻链接

先读源商品和真实前台图片，核对来源权利、目标店、类目、品牌和完整销售规格。源 SKU、目标 SKU 与新商品 ID 分别追踪。信息分槽图与前台轮播用途不同。复刻现有商品时，核实共享轮播、各规格首图及排序，再判断哪些素材可以直接沿用。

从 `run photo-listing -- init` 建立本地任务包；本店源商品可用 `--source-spu`。报价前检查真实类目支持的销售维度、标题、规格事实和平台要求。详情的张数取决于商品还需说明的事项。价格、库存、物流和服务承诺有缺口时，只问影响交付的具体决定。

新图由宿主逐图设计，注明目标规格、参考图、要表达的真实卖点及依据。使用 `make-plan` 计算复用与新增图位。商家只要样张时转[样张流程](experience-images.md)。商家只交办出图时保留本地产物；交办发布时沿用原任务审核、准备、提交和读回。以后台实际产品与规格核验结果交付 SKU 链接，说明前台是否已实开检查。
