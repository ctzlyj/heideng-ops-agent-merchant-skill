# 采集、比价和已有视频

**采集。** `run collection` 按商家选定来源读取商品，并保持原规格、顺序、价格条件和图片归属。用覆盖的真实规格数和未取到的项目说明结果。阶段检查点可用于续办已有批次。目标是收集资料时只交付素材与表格。

**比价。** `run comparison` 先按数量、型号、单位、组合、配送和促销条件对齐。标注来源、采集时间、优惠前后口径和缺项。经营建议要结合库存、真实成本和商家目标，调价须有单独的商品范围与价格决定；写入后读取对应规格的实际售价。

**现有视频。** `run video-handoff` 检查成片、封面、内容版本和商品映射；需要绑定时由 `run video-binding` 按目标 SKU 和原视频 ID 处理。分别交付本地文件、上传、转码、绑定及平台审核结果。文件或目标改变时核对覆盖范围。上传结果未知时保留原文件哈希、原请求和关系回执，先查远端。
