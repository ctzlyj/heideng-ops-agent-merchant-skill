# 核对店铺与任务范围

商家可能用简称或品类称呼店铺。在 0.4.20 工程联调中，`card-shop-identity` 使用已连接的商家专属 Profile 读取官方店铺身份，将店铺名称、shopId 和 venderId 与原任务的同名字段分别核对。多家近名店或同一主体下有多店时，以商家确认的目标及平台身份区分。

开始全店写入前检查目标范围。按店查历史任务时，将已核验的两个 ID 传给 `task-context --shop-id <shopId> --vender-id <venderId>`。已知是原复刻链接则加目标 productId；同一来源已经复刻两次时展示可区分的 SKU 链接或规格。

依赖未就绪或身份不符，返回该店铺步骤的阻断状态。正式连接器依赖及客户端卡片尚待验收。本地已接受样图、已有经营报表等独立证据可按任务继续核对。
