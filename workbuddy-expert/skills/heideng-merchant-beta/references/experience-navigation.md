# 按商家问题选经验

宿主负责理解目标、确定优先级、组织独立工作。通过专家的 `merchant_command` 调用相应工具。联调包在本地回执、已有报表和原图片计划范围内工作；下表中需要京麦实时数据的场景留待店铺连接器就绪后验证。

| 商家交办 | 先用的证据与经验 |
|---|---|
| “看看我这家店” | [店铺与范围](experience-connection.md)；核对最近业务目标及仍需处理的项目。 |
| “把全店商品信息分维护好” | [商品内容](experience-materials.md)；先交付盘点和免费修复。 |
| “把这条链接复刻并上架” | [上新](experience-listing.md)；核对来源、目标规格、价格、品牌和平台发品要求。 |
| “先改一张给我看看”或“昨天那张继续” | [商品图与样张](experience-images.md)；选单张打样或找原样张。 |
| “广告花得多，还退货，先做什么” | [经营与服务](experience-diagnosis.md)；对齐数据口径，给出一个优先动作。 |
| 采集、比价、调价或绑定现有视频 | [采集、价格与视频](experience-commerce-media.md)；分别核对来源、比价口径、操作范围与回执。 |

商家问“做到哪了”时，从已核对的店铺调用 `task-context`，可按商品、来源商品或目标（materials、listing、creative、sample、sku-edit、diagnosis）筛选。对多个合理候选只问一个能区分目标的问题。保留原计划和已消耗额度。平台给出待审和结果未知时，优先读原业务回执。
