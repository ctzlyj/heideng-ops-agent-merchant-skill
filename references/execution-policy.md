# 执行规则分层

## 六类规则

| 类型 | 示例 | Agent 可否调整 |
|---|---|---|
| 经验建议 | 通常先审源资料、建议先小批处理、常见参考顺序 | 可按任务改变；说明理由即可，不加审批状态 |
| 可配置执行策略 | 本任务批次、并发、选择范围、是否复用已合格素材 | 可在工具支持与已批准范围内配置；范围/费用变化需说明 |
| 平台/接口硬限制 | 真实批量上限、图像尺寸/格式、SKU对应、当前销售属性写法 | 不靠改文档或换入口规避；官方规则变化时先读当前契约 |
| 身份/授权/预算/真实性 | 当前商家环境、正确店铺Profile、写入范围、模型/平台/价格预算、真实证据 | 不削弱，不借员工凭据、不假造结果；同范围已有批准直接沿用 |
| 未知写入恢复 | 原提交超时/无正式终态、导入任务未知、上传保存绑定不明 | 先关联原任务/回执和远端状态，不能换工具重提/删状态 |
| 开发验证要求 | 发布资料检查、本轮不做真人扫码/付费测试 | 属于开发/交付记录，不是商家未来业务的长期禁止令 |

工具本身的未实现能力（例如某复杂促销公式）只说明该工具边界。Agent 可采用其他合法、可验证方法，但不能猜公式、绕权限或因换工具重复写入。

## 交办与范围

用户不交办就不开展业务，不自建定时运营。安装、授权或可用 Key 不等于全部店铺动作获准。明确批准过的同店/商品/动作/覆盖范围/模型与费用，作为这一次任务的共同授权上下文；组合模块不再让用户重复答同一个批准问题。真正改变店铺、扩大覆盖、覆盖现有素材或增加费用时，说明差异再取得相应批准。

新授权、重新授权、改价、发布、绑定或付费是否需确认，沿用原成熟流程和用户本次明确授权；不再增加第二套黑灯 plan/approve 门禁。只读任务不要求配置本任务不用的生图/视频服务。

## 身份与工具切换

成熟来源包装器只能运行登记入口，这是安装内容/完整性保护；官方 Skill、宿主工具、任务局部脚本并不因此被全局禁止。直调 jdo-cli 的前提仍是本商家独立执行文件与环境、明确非 default Profile 和实时目标身份。参见 [环境桥接](merchant-cli-environment.md)。

网页登录身份和 CLI venderId/shopId/shopName 必须匹配。网络异常不是授权失效；已有授权用实时调用判断，不凭本地过期时间强迫扫码。不得导出 Token、复制员工浏览器/凭据、用另一家店试写。

## 结果与未知恢复

区分准备完成、提交被受理、平台审核、线上生效、经营改善。截图、HTTP成功、目标值恰好相同或本地 fixture 不能替代对应业务证据。数量只统计实际响应/回读覆盖，不把未知、未提交或缺数据算完成。

未知写入由原业务回执/状态保留。工具切换可以用于读取、诊断和关联原请求，不是新提交许可；不得手改 receipt/SHA/QC、关闭完整性或删除未知状态。只有能按原接口/任务关联的正式结果才按原恢复路径继续；未能解决时报告已完成部分与未决范围，不追加重复写入。

## 模型与私人数据

分批制作时，宿主先按商品目标选定具体图位。例如六个图位最多做五次，应说明优先做哪五个、余下一个沿用原图还是暂缓。原报价含 `canSelectUnits: true` 时，在 `confirm-image-fee` 加 `--units <图号1> <图号2> …`；待做范围与次数冲突会在商家看到确认窗口前返回。执行时沿用原任务目录与完整设计，已批准图号交给模型，其余图号及下一步保存在原任务回执。整套发布前补齐或复用所需图片。后续批次用最新报价，原结果未知先对账。

两款模型以本次实际请求画质计费：1K 3 积分、2K 4 积分、4K 5 积分。混合画质逐项加总，说明所选新增图位、预计积分和含返工的总上限。商家只在本机费用窗口做一次决定；新报价运行 `scripts/merchant.py confirm-image-fee --quote <报价.json> --output <费用回执.json> --max-requests N`。原范围内剩余额度可继续使用；需要再次提交结果未知的图片时先只读对账。账户已消耗积分及余额以 LTS4AI 后台为准，不能用本机计数代替。

已有 LTS4AI / gpt-image-2.6 与 gpt-image-2.5 配置、用户选择的平台/费用/预算不会因为开放执行而变化。商家 Key 不落聊天、日志、源码或截图；不使用公司 Key/额度/模型回退。外部 AI 视频尚未配置，不假装已经替换；已有视频交接仍可按原条件进行。

商家记忆、运行数据、任务结果、浏览器 Profile 和凭据在独立状态/任务目录；升级不覆盖，不打包。公共经验维护必须保留来源/适用条件，不把某店某月结论推广为所有店的硬限制。
