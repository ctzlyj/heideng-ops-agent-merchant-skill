# LTS4AI 商家生图

中转站由黑灯运营方管理。商家版使用 `https://api.lts4ai.com/v1` 的生图及参考图编辑接口。新批次允许 `gpt-image-2.6`、`gpt-image-2.5` 同时执行不同的图片；只有一张时发送一个请求。原任务已有模型限制、已受理请求、未知回执或可复用图片时先读取原记录。以每张实际请求的模型和回执核对结果。

维护者确认两款模型同画质同价，1K、2K、4K 每张分别为 3、4、5 积分。一张 1K 加一张 4K 预计 8 积分；可复用的图片从新增数量中扣除。每个获批请求占用一份额度，可能已提交但没有回执的请求仍计入预算预占。商家内测额度、实际扣减和剩余额度由 LTS4AI 后台管理。不能把本机预占推算成账户余额。

普通 Skill 继续使用对应商家获准的 Key。定向内测专家使用每商家专用 Key 验证内测资格，之后按该 Key 调用中转站。店铺登录与授权使用京麦官方凭据。密钥通过本机安全输入或已验证的专用注入路径传递。额度不足、撤销或过期时保留任务回执和已完成的图片，不换其他平台或账户继续消耗。

图片传输复用包内的 SUFY 客户端，提交层重试为零。确有超时先核对原请求；已付费响应未知时不能用另一个模型代发同一张。不同图位的速度取决于中转站并发、排队、规格和网络；发起并行请求不代表供应商已经完成出图。
