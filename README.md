## 安装提示词（发给你的Agent）

请安装 GitHub 仓库 ctzlyj/heideng-ops-agent-merchant-skill 的黑灯运营智能体商家版。复用当前Agent已有的GitHub读取权限，下载当前经审核发行版并核对SHA256；由你执行install.py，将唯一入口heideng-ops-agent-merchant安装到当前宿主的独立skills目录，再运行onboarding带我上手。不要改动内部版或使用内部SkillHub，不要让我手敲命令、复制Cookie、授权码或Key。店铺相关功能缺官方CLI时，你从京麦官方公开通道校验安装；需要新授权时，我只扫码并完成本人确认。

**当前先私有交付**：安装者必须已有仓库读取授权；不能把私有链接说成任何商家均可下载。公开、公司成果分发和第三方商用许可由负责人另行决定。

## 可直接描述的目标

- 帮我核对这份商品资料并保留全部规格，整理成实拍上新包。
- 分析这份经营和广告报表，指出数据缺项，不自动投广告。
- 整理这些同规格商品的逐SKU到手价，出TOP10和待确认调价方案。
- 核对这批商品信息分和素材缺口，复用已有合规图片。
- 采集这些商品的真实SKU顺序、到手价、主图/详情素材，保存成包。
- 用我提供的视频和封面准备主图视频交接，先复核再确认绑定。
- 连接我的POP店铺并查询商品；任何写入给我看明确范围再提交。
