# 黑灯运营智能体商家版 0.4.6

本地 WorkBuddy/JoyCode/Codex 等宿主 Agent 理解和规划商家自然语言任务；黑灯提供电商经验导航、独立安装更新、协作边界和成熟执行工具。**经验目录不是能力白名单，status/run只是一个受保护的成熟包装器。**

## 给宿主 Agent 的安装入口

从本仓库源码/解压目录运行：

```text
python install.py --host codex --with-runtime --with-official
```

标准在线安装会同时准备神经抠图依赖和固定 SHA 的 Lite 权重（首次约 214MiB）；离线安装不下载，未就绪项可稍后单独恢复，不影响其他能力。

JoyCode 用 `--host joycode`；WorkBuddy/其他宿主使用其实际 `--skills-dir`。独立安装名与商家状态/Profile不覆盖内部版、个人Skill、商家记忆或任务结果。版本升级和同版本异包/哈希保护保持。

商家直接交办目标。Agent从 [主Skill](SKILL.md) 和 [经验导航](references/experience-navigation.md) 按需加载连接、内容信息分、上新、图文、采集、比价、诊断或视频经验，可跨模块组合、采用宿主工具/官方当前能力和任务局部脚本，不需要先按关键词运行route。

目录外官方CLI也用 [商家隔离环境](references/merchant-cli-environment.md)。原成熟派发仍为 `python scripts/merchant.py run [--entry scripts/已登记入口.py] <capability> -- <原参数>`；不启用旧builtin、不开放任意entry、不删除provenance保护。

## 当前边界

图片保留LTS4AI / gpt-image-2.5与商家自己的Key，不使用公司凭据/额度。独立文本/视觉API未配置时可走成熟宿主生成文件路径；只读任务不要求生图Key。外部AI视频生成仍未配置，已有真实成片交接/上传绑定是不同的成熟能力。

身份、用户本次授权与预算、平台真实限制、未知写入回查和结果真实性不可因开放执行削弱。用户不交办不开展运营，不自建定时系统；同范围已有明确批准不加第二套确认。

## 来源与交付事实

新经验页实际进入package-files和安装manifest；mature受保护源码/许可/来源hash不变。原历史commands/workflows只在源码标记历史，既没有在0.3.0安装包使用，也不为它们恢复旧runtime。商家诊断经验提炼商家已授权京麦/商智/京准通与用户报表，员工EasyBI/黄金眼、固定历史月份不是商家工具/任务参数。

0.3.1上一轮是文档、导航、元数据与分发局部优化；0.4.0仅新增软件持续更新机制，不是重新研发电商业务。静态资料/清单检查不等于真实商家授权、导入、写入、外部服务或各宿主实机通过；具体开发范围和未实测事实保存在源码docs/experience-navigation-0.3.1-2026-11-17.md，不作为产品长期禁止令。

不创建Release、不改变仓库可见性、不通知商家。当前默认分支作为统一GitHub分发入口，商家需有相应仓库访问权限。

## 持续更新闭环

0.4.0新增维护端增量候选、签名固定Git blob稳定索引、客户端默认开启的24h入口触发空闲升级与版本租约。原成熟业务不重迁移，原安装回执/锁/中断恢复保持。详见references/continuous-updates.md。

商家自己的私有仓库读取授权和Git必须可用；没有权限/依赖则deferred，原版继续用，不自动登录。0.3.1安装尚无更新组件，需要宿主首次升级到0.4.0；后续检查不要求商家理解终端。未安装/未授权的商家电脑不能被说成已经自动更新。当前聊天不会因磁盘替换立即刷新，按宿主新任务节点与usage快照处理。


## 0.4.4 商家实测衔接修复

生图提示词原样保留。本轮修任务范围、真实槽位、官方详情参考图、同店浏览器类型、解释器发现、安全输入、执行锁和大批输出；业务仍由成熟 Skill 实施，宿主 Agent 规划。详细经验在 references/experience-materials.md。

商家只需把获准访问的本仓库交给宿主：按宿主实际目录安装一次（WorkBuddy标准路径用 `python install.py --host workbuddy --with-official`；其他配置用 `--skills-dir`）。核心依赖默认准备；不在安装时要求生图 Key、扫码或运行经营任务。然后直接提出“连接我的店铺”“只维护这个商品”等目标，宿主加载对应经验、复用已有授权并执行成熟入口。首次生图需确认范围/费用，通过本机密码输入商家自己的 Key，可明确选择系统安全记住。

已有0.4.0且本机私有读取权限、安装完整性和版本租约正常时，可经签名稳定索引发现0.4.4、空闲切换；核心依赖清单没有变更，未改变原依赖指纹保护。旧0.4.0只装更新依赖的情况，在新版实际素材任务前补齐原核心依赖，而非要求商家手工修解释器目录。磁盘更新不代表当前聊天已刷新；后续任务由宿主在允许节点加载新版，不强制重启。

源码/离线升级演练不等于商家已升级或真实店铺验收。macOS Keychain与实际WorkBuddy/Edge浏览器仍需对应设备检查，不冒称本轮已在这些设备生图/导入通过。私有仓库无读取授权的电脑仍不能自动获取新版；禁止发送维护端GitHub凭据。
