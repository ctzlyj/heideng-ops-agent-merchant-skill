# 连接体验与交付闭环 Implementation Plan

**Goal:** 复用成熟连接/OAuth，在WorkBuddy等宿主不再靠临时脚本完成新店连接。
**Architecture:** 连接器仍为唯一业务/身份状态源；补宿主生命周期与浏览器控制薄适配。原Profile隔离、店铺核验、OAuth与未知结果保护不变。更新继续使用签名固定发行物。
**Spec:** 用户批准的0.4.1完整实战复盘：30条主消息、337条工具记录，聚焦HD044-HD058/060。

## 不变量
- 基线afc0ad2/0.4.1，隔离工作区；旧目录、内部版、个人Skill只读。
- `_shared_image_rules`、`image_prompt`原文不改，HD059不纳入实现。
- 不真实扫码、店铺写入、改价、付费生成；宿主假页面/隔离服务只做本轮适配验证。
- 不把长超时当恢复；不把环境缺失误报网络失败；不取消同店已有任务，不覆盖unknown回执。

## 实施
- [ ] 失败测试：原连接器服务 detached 启动、CLI退出后Job仍可消费；失败后同店不返回旧failed job，显式resume复用Profile。
- [ ] 失败测试：HostBrowser短动作超时不杀死授权，平台challenge可读、京麦页面校验、登录页不强迫扫码；confirm契约/超时与未知结果分开。
- [ ] 提供可运行宿主浏览器控制适配：owned profile、真实页面读取/点击、OAuth确认、非敏感最小回执。宿主仍掌握商家本人动作；不新建业务规划引擎。
- [ ] 更新运行时解释器、商家版Key路径升级、盘点出图口径、经验文档；发布最终树==固定包校验。
- [ ] 局部离线/隔离服务验证、真实固定源交付；不宣称跨宿主或真实授权已验收。

## 验收目标
老店ready不启动服务；新店一次任务可持续等待；宿主退出命令不消Job；浏览器操作迟回不永久unknown；风控有明确本人指引；同店恢复不新建身份。实际京东页面/扫码/OAuth仍标真实内测项。
