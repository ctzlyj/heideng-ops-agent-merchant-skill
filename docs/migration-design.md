## 1. 产品与授权边界

展示名「黑灯运营智能体商家版」，独立 Skill 名 heideng-ops-agent-merchant。面向 POP 商家本人，用户描述目标，Agent 自主组合已审阅能力、官方工具、商家有权限的浏览器接口和任务内局部脚本。能力清单用于发现、安装和来源管理，不是能力白名单；权限、店铺身份、费用与数据来源边界不可绕过。

不建设 SaaS、支付、账号中台或统一代付。商家自带合法外部账户，不共享员工 ERP/SSO、公司模型额度或集团平台账户。不得修改内部版及其安装、更新、配置、凭据和店铺运行数据。

研发授权不包含真实上架、改价、素材绑定、发送消息、付费生成或公共发布。许可与公司成果归属未核实前，不将现有资源视为个人可收费成果；源仓库有 MIT 文件也不等于本项目全部资源完成公司归属审核。

## 2. 推荐架构（实施者建议，待批）

Python 3.11+ 轻量本地包：核心安装、校验、策略、任务状态与适配尽量使用标准库；成熟业务和视频运行时使用独立虚拟环境。Node/FFmpeg/浏览器按相关能力需要接入，不改全局环境，不启动员工服务。

推荐「独立总调度 + 轻量策略/provider 层 + 选择性商家适配 + 可更新上游」，不整体复制内部包，不从零重写全部业务，不搭服务平台。

| 部分 | 职责 |
|---|---|
| 独立 SKILL/能力登记 | 自然语言路由、来源、版本、许可、输入输出与可用性 |
| 安装更新器 | GitHub/经审核发行物下载、来源与哈希、路径安全、失败恢复/回滚 |
| 策略安全层 | 专用凭据槽、子进程环境过滤、媒体出口、店铺与写入授权 |
| provider 层 | 外部文本/识图/生图/视频/配音实际协议、价格证据和任务查询 |
| 任务费用层 | 输入指纹、持久化原子预留、次数/预算、未知结果阻断、只读恢复 |
| 业务薄适配 | 复用成熟算法，替换公司模型/内部入口/旧视频依赖 |
| 视频桥接 | 固定上游审核版本、本地媒体/QC/试听/manifest 交接 |

缺许可、平台、Key、价格证据、授权或输入时只阻断对应步骤，继续无关工作；入口可用不等于业务已可用。

## 3. 独立命名空间与店铺

仅把独立总调度和 merchant 前缀适配注册给宿主；可变业务依赖及原视频代码置于商家运行时目录，不暴露未经处理的上游 SKILL，避免 Agent 直接命中内部体验提示词。

安装示意 <host-skills>/heideng-ops-agent-merchant；运行时、任务、回执、候选下载与回滚位于 <merchant-state>/。发行文档只存相对路径/占位符。不要写内部 Skill、不沿用内部更新任务名/渠道、不修改原自动更新任务。第一阶段用启动时或显式更新检查，不创建后台定时任务。

官方 jdo-cli 二进制可在兼容时复用；每次明确非 default Profile，实时核对店名、venderId，必要时核对 shopId。Profile 名不同不是凭据隔离证明。商家登记独立，不导出/复制官方凭据，不扫描所有店铺自动接入；目标明确且身份一致才能引用已有授权。

CLI 配置/凭据目录官方隔离能力仍待验证。如果官方调用更改共享配置，不能声称内部数据字节级不变，也不靠猜测 HOME 覆盖来宣称支持。离线共存先用假 CLI，实机链路另验收。

## 4. 外部 provider 和 Key

外部平台尚未指定：第一版默认未配置，仅 mock 可用。方舟是指定视频上游已有直连候选；LTS4AI/sufy-image2 是图片候选；宿主已有外部能力可按实际合同接入。LibTV 仅用户主动选择时考虑，不能要求集团账户；Yeta 为上游试用候选，不自动选用。

非敏感配置记录 provider ID、官方域名、模型标识、能力、尺寸/时长/参考图限制、同步/异步协议、查询、计价来源/日期/单位。实际模型和价格需要官方当前资料与用户账户核对；上游历史价格不是当前报价，不因协议相似推断支持。

Key 使用商家专用 OS 凭据槽或受控进程环境，通过安全窗口/可信管道输入。不进入聊天、argv、源码、.env、日志、截图或 Git；不从员工环境、注册表用户环境、旧 company Key、sufy 默认共享槽自动取值。选定外部账户后，只注入该运行时必需的已审阅外部变量名。

媒体专用 transport 校验 HTTPS、明确外部目的主机与端口，拒绝内部域名、私网/回环/链接本地目的地址、异常重定向和返回 URL 内网跳转。模型调用与无鉴权媒体下载分开，不把 Authorization 附到 CDN；不继承未审核代理、PYTHONPATH、preload 和插件路径。合法 JD 业务由官方 CLI/商家已授权接口处理，不能用「禁止全部 jd.com」破坏 POP。

默认、失败回退、显式参数、配置覆盖、旧任务恢复全部禁用公司网关、oxygen-h3、员工体验和集团账户。不能只改说明或环境变量名称。

## 5. 费用和未知状态

一次批准绑定任务指纹、来源商品/规格、provider/模型、图片/镜头数、允许的重试/重生数、费用范围/硬上限、价格证据版本。同范围不反复问；更换付费平台、模型、数量、来源或提高预算是新范围。

全部付费路径（策划/识图/帧/视频/ASR/TTS/QC）进入共同闸门。先原子预留金额及次数，再提交；跨线程/进程证明同一操作只被接受一次。没有预算和数量批准不付费。

先持久化 submitting；拿到 ID 转 submitted；成功下载并验证才 completed。超时、断连、5xx、无法解释响应、崩溃和未完成提交均为 unknown，保留预算与次数，不自动退款或重提。只有平台合同证明未受理的拒绝才能释放。

相同来源/参数 unknown 阻断新任务与换工具重提。有 task ID 的恢复只查询/下载；无 ID 依平台幂等/查询能力核对，必要时请用户查任务列表，不建议删除状态文件解除限制。不重跑上游整条 pipeline 冒充只读恢复。

## 6. 视频与上新

固定来源 ctzlyj/jd-pop-main-video-skill；当前审计 0.3.0 / 29548089f7b71ac77ddb584caac0966a98df24ab。不依赖 jd-main-video-batch/11190，不修改视频原仓库。

商家包装器管控 provider/凭据/网络/账本/输入指纹/错误/恢复，复用上游身份锁定、事实策划、首尾帧、视频协议及 QC。此保证仅覆盖已审阅商家入口，不是对任意宿主脚本的全局沙箱，不开放 raw 执行或任意覆盖。

两类真实输入：
1. 已上架链接/SKU：真实商品及选中款事实。
2. 未上架 listing-package：manifest、用户实拍、SKU/规格/卖点，通过商家组合器调用上游可复用模块。不伪造链接、SKU、网页或 task ID。上游 main 当前不支持本地包；组合器离线输入/接口验收属于第一阶段，真实生成仍需授权。

上游没有 manifest.video 发布协议，旧上新 video_handoff 硬依赖 11190。商家定义版本化交接：相对 localPath/coverPath、真实文件 SHA256、来源指纹、上游 commit/文件清单、真实平台 task ID、自动技术 QC、视觉复核、试听及风险状态。未实质复核时 bindable=false；不能补字段把旧包伪装成已验收。

生成文件与上传/绑定是不同能力。写入前再次核对店铺、Profile、商品和文件哈希，取得对应写入批准；由官方 POP 工具提交并核对远端回执，不把文件存在说成绑定成功。

## 7. 外部安装更新

清单保存 repo、版本/commit、许可状态、已审阅文件哈希与兼容入口；任务保存实际版本。版本记录用于复现，不是永久锁定。

发现 HEAD/发行版本 → 隔离候选下载 → 路径/大小/文件/哈希与脱敏审核 → 检查新增依赖、媒体路由、接口变化 → 自有离线契约回归 → 满足来源与审核要求才激活。传输 SHA256 不等于代码安全证明，同源哈希不解决作者许可。

有任务、未核对提交、本地修改时不切换；运行快照不可变。unknown 不因进程退出就 idle。不自动降级，不覆盖用户修改或开发链接。切换失败恢复原完整版本；明确回滚不是自动降级更新。

默认先私有 GitHub 研发仓库；此时安装者必须已有该仓库读取权限。完成许可和分发审核、用户另行批准公开/发布后，再交付商家可访问的发行入口。不会把开发阶段私有链接写成任何商家均可安装。
