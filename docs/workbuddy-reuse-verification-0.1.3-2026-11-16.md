# 0.1.3 开发检查点验证：成熟能力复用、WorkBuddy HD-007/008

验证日期：2026-11-16（Asia/Shanghai）。源码基线：9db34b12eb336f5a782efdd10300e640c3f0346b；候选版本：0.1.3。安装候选应取**包含本文的提交**，不是上述旧基线。本轮仅推送开发分支，不创建 Release，不通知商家更新。

## 修改范围

- 所有能力默认优先复用已验证实现，只允许必要的商家权限、模型来源、宿主和分发薄适配；未重写成熟上架、短标题、素材、诊断、生图业务。
- 新店连接恢复原 jingmai-cli-linker 的 HostBrowser/controller 动作契约，不扩大猜测域名/字段白名单。Agent 复用已有浏览器 CLI/SDK，准备任务局部控制器，从已观察接口或可靠 DOM 取得真实身份；控制器未准备则在启动 worker 前明确停止。不是将无许可原应用整体搬进仓库。
- 继续复用现有 BrowserRuntime，保留官方 CLI 的 psutil 回调归属和进程收尾依赖；不切换到缺依赖的基础解释器。
- Windows 恢复核对 launcher 与实际 worker 两个 PID、任务归属、时间证据、双锁和未变化原件，不要求两个 PID 相等；只有确证退出、OAuth 未开始且无授权/清理未知，才能安全重启。
- OAuth 导航前强制刷新会话身份，不依赖节流缓存；首次 browser 动作结果不明且无归属回执时保留清理未知，禁止重复打开和重启；同任务 OAuth 不重复派发。
